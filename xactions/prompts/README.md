# prompts/

Prompt documents used to plan and generate parts of this codebase with AI coding assistants.

- `builds/`: numbered build prompts (`00-MASTER-ORCHESTRATOR.md`, `01-SCRAPER-LIBRARY.md`, ...) that describe each subsystem well enough for an assistant to build or extend it.

Nothing here is loaded at runtime. Paste a prompt into Claude, Cursor, or Copilot when you want to regenerate or extend the subsystem it describes. The 22 end-user Claude tutorials live in `tutorials/`.
