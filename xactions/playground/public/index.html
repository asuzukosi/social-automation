Same query, every interface

What runs here and what does not. X serves profiles and public timelines to a logged-out client, so everything on this page works with no account at all. Search, followers, likes, bookmarks and DMs need a session, and X answers a logged-out request to those with a bare 404. Those work locally once you connect your own session with npx xactions connect, which never leaves your machine.

Step 1

Run it on your machine

Same query, no rate limit, results you can pipe into a file.

npx xactions profile nasa Step 2

Unlock the session tier

One command opens a browser, you log in as normal, and it captures the session. No DevTools.

npx xactions connect Step 3

Give it to your agent

144 tools over MCP, so Claude, Cursor or Windsurf can do this in plain language.

npx -y xactions-mcp
