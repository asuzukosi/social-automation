# dashboard/

The static web dashboard: plain HTML, CSS, and JavaScript, no build step. Pages cover automations, analytics, scraping, AI tools, billing, and admin.

Serve it with the API (recommended, the pages call `/api/*`):

    node api/server.js      # http://localhost:3001

Or serve the static files alone:

    node dashboard-server.js   # http://localhost:3000

`js/config.js` holds the shared helpers every page expects (`apiRequest`, `formatNumber`). `docs/` and `scripts/` are generated by the site build (`npm run site:build`). Page list: [docs/dashboard.md](../docs/dashboard.md).
